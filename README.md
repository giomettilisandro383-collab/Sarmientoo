# Trabajo Práctico — Efemérides escolares de Argentina y Próceres argentinos
### Prócer elegido: Domingo Faustino Sarmiento (1811–1888)

## Estructura del proyecto

```
sarmiento-web/
├── index.html          → Página principal (efemérides, historia argentina, línea histórica, importancia del prócer)
├── vida-obra.html       → Sección 1: Vida y obra
├── efemerides.html      → Sección 2: Efemérides, lugares y monumentos
├── legado.html          → Sección 3: Legado, curiosidades, frases y galería
├── css/
│   └── style.css        → Hoja de estilos externa (paleta, tipografías, componentes)
├── js/
│   └── script.js        → Pequeño script de UX (resalta el link activo del menú)
└── README.md
```

## Requisitos HTML cubiertos
- 4 archivos HTML, estructura HTML5, `index.html` como archivo principal.
- Hoja de estilos CSS externa (`css/style.css`) y comentarios en el código.
- Como mínimo: 3+ títulos (h1–h4), 6+ párrafos, 1 tabla por página, imágenes con crédito,
  1 video incrustado con crédito, listas ordenadas y desordenadas, nav con 4 links,
  palabras/frases enfatizadas (`<strong>` / `<em>`), saltos de línea (`<br>`), distintos
  niveles de título y un botón fijo de "volver al inicio" en todas las páginas.
- 1 link externo a una fuente confiable en cada página.

## Requisitos CSS cubiertos
- Fondo de imagen en el header, fondo de color en el nav y en el footer.
- Uso de `id` y `class`, cajas, márgenes, padding, bordes, tipografías y posicionamiento
  trabajados de forma personalizada (no son los estilos por defecto de Bootstrap).

## Componentes de Bootstrap utilizados (más de 4)
Navbar · Cards · Accordion · Modal · Carousel · Tablas con clases de Bootstrap · Botones.
